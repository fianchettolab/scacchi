# Scacchi

Chess rules for Swift: legal moves, SAN, FEN and every ending, built on
[shakmaty](https://github.com/niklasf/shakmaty) by Niklas Fiekas, the chess core
behind Lichess's tools.

*Scacchi* is Italian for "chess", as *shakmaty* is Russian for it.

It's part of [Fianchetto Lab](https://github.com/fianchettolab), a set of chess
experiments, and comes as-is. It isn't affiliated with shakmaty.

## What it does

```swift
import Scacchi

let game = try Game.fromFen(fen: "r3k2r/8/8/8/8/8/8/R3K2R w KQkq - 0 1")
game.legalMoves()            // ["a1a2", …, "e1g1", "e1c1"], in UCI
try game.play(uci: "e1g1")   // PlayedMove(uci: "e1g1", san: "O-O", isCapture: false)
game.status()                // .ongoing, .checkmate(winner:), .draw(reason:)
game.board()                 // the pieces, squares a1 = 0 … h8 = 63, and the side to move
game.checkers()              // the pieces giving check
game.fen()
```

Draws cover stalemate, insufficient material, threefold repetition and the fifty-move
rule. `Game` is `Sendable`: it locks inside.

## Layout

| Path | What it is |
|---|---|
| `src/lib.rs` | The Rust crate: `Game` over shakmaty, exported with UniFFI's proc macros |
| `src/bin/uniffi-bindgen.rs` | UniFFI's bindings generator, pinned to the crate's version |
| `build-xcframework.sh` | Builds `build/ScacchiFFI.xcframework` and regenerates the Swift bindings |
| `release.sh` | Builds, zips and tags a release, writing its version and checksum into `Package.swift` |
| `notices.py` | Writes `THIRD_PARTY_LICENSES.txt`: the licence of every crate linked into the library |
| `Sources/Scacchi/Scacchi.swift` | Generated by the script; committed, so Swift users need no Rust |
| `Tests/ScacchiTests/` | Swift tests of the bindings |
| `Package.swift` | `Scacchi` over the `ScacchiFFI` binary target: the release's zip, or a local build when there is one |

## Building

You need Xcode and Rust (1.97 or later):

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

Then build the XCFramework (iOS device, iOS simulator and macOS, Apple silicon) and run
the tests:

```bash
./build-xcframework.sh
cargo test
swift test
```

The first build takes a few minutes.

To work on the bridge from an app that uses Scacchi, check it out next to the app, build
it, and drag the folder into the app's Xcode project as a local package override. A local
`build/ScacchiFFI.xcframework` wins over the release download. SwiftPM caches the
manifest, so after creating or deleting a local build, touch `Package.swift` (or reset
package caches in Xcode) for the switch to take effect.

Apps that ship Scacchi should include `THIRD_PARTY_LICENSES.txt`; re-run `./notices.py`
after changing dependencies.
